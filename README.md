# Счётчик OCR — PWA для iPhone без Mac

Это веб-приложение для распознавания показаний счётчика через камеру iPhone. Его можно разместить на GitHub Pages и добавить на экран iPhone как обычное приложение.

## Что умеет

- камера iPhone через браузер;
- снимок табло счётчика;
- OCR через Tesseract.js;
- выделение числового показания;
- ручная корректировка;
- история показаний в памяти телефона;
- экспорт CSV;
- установка на экран iPhone через Safari.

## Как разместить на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `meter-ocr-pwa`.
2. Загрузите все файлы из этой папки в репозиторий.
3. Откройте `Settings` → `Pages`.
4. В `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Нажмите `Save`.
6. Получите ссылку вида:

```text
https://ваш-логин.github.io/meter-ocr-pwa/
```

## Как установить на iPhone

1. Откройте ссылку GitHub Pages в Safari на iPhone.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран Домой» / «Добавить на экран Домой».
4. Включите «Открывать как веб-приложение», если iOS покажет такой пункт.
5. Нажмите «Добавить».

После этого на экране iPhone появится иконка приложения.

## Важные ограничения

- Камера работает только на HTTPS. GitHub Pages подходит.
- При первом распознавании нужен интернет для загрузки OCR-библиотеки Tesseract.js с CDN.
- Точность зависит от качества фото, бликов, шрифта счётчика и положения цифр в рамке.
- Для промышленного решения лучше добавить серверное OCR или ML-модель, проверку аномалий и привязку к лицевому счёту.

## Как улучшить точность

- Наводите камеру строго на цифры.
- Уберите блики фонариком или изменением угла.
- Держите телефон ближе к счётчику.
- Размещайте цифры внутри рамки.
- После OCR всегда проверяйте результат вручную.
